# Electronic supplementary materials

This directory contains the public supplementary material for the study
*Beyond Point Accuracy and Rule Compliance: Layered Evaluation of a Constrained
Neuro-Symbolic Decision-Support System*.

## Files

- [`ESM_1_Supplementary_Material.pdf`](ESM_1_Supplementary_Material.pdf) is the
  reader-ready version.
- [`ESM_1_Supplementary_Material.docx`](ESM_1_Supplementary_Material.docx) is
  the editable source version.

Both versions contain the same four supplementary tables:

- **Table S1:** pooled action confusion matrices for the integrated backbone
  and the full method.
- **Table S2:** seed-level preferred-action accuracy, Macro F1 and Top-2
  agreement for every neural configuration on the original 19-case cohort.
- **Table S3:** reliability-bin composition for raw and temperature-scaled
  probabilities.
- **Table S4:** review-state composition for the original seed-42 audit.

## Link to the frozen evaluation output

The repository source for Table S2 is
[`outputs/confirmatory_evaluation/seed_metrics.csv`](../outputs/confirmatory_evaluation/seed_metrics.csv).
The CSV retains the unrounded seed-level values used to prepare the displayed
supplementary table.
